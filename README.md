
# Python Password Manager

A beginner Python project that allows users to manage website login information through a command-line interface.

## Features
- Add password records
- View saved records
- Search for a website
- Delete password records
- Generate random passwords

## Concepts Used
- Python dictionaries
- Loops and conditional statements
- Functions
- Random password generation
- String module

## Disclaimer
This project is created for educational purposes only. Passwords are currently stored in plaintext and should not be used to store real credentials.
